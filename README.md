# senior-dog-guide-sitemap-mirror

これは「シニア犬のくらし手帖」(本体サイト: https://senior-dog-guide.pages.dev/ )の
サイトマップを、別ホスト(GitHub Pages)から配信するための検証用ミラーです。

Google Search Consoleで本体サイトのサイトマップ(Cloudflare Pages配信)が
取得失敗を繰り返している原因を切り分けるための一時的な実験であり、
本体サイトのソースコード・記事・画像は含みません。

含まれるファイルは `sitemap.xml`(本体サイトの公開URL一覧)のみです。
